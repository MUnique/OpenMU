# Startup

The startup console program is basically what glues all components together and
starts the server as a single process.

Its documentation moved to the documentation website:

* [Startup parameters and environment variables](../../docs-website/docs/deployment/startup-parameters.md)
  — the start parameters, the environment variables, the `-resolveIP` values,
  the externally-provisioned database setting, logging, and the priority between
  all of them
* [Run from source](../../docs-website/docs/getting-started/from-source.md) —
  building and starting the server for development
* [System configuration](../../docs-website/docs/admin-panel/game-configuration.md#system)
  — the same settings in the admin panel, which is the more convenient way for
  most of them
