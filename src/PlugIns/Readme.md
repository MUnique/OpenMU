# MUnique.OpenMU.PlugIns

This project contains the building blocks for the plugin system of OpenMU and
doesn't have any dependencies to other OpenMU projects — so it's reusable, if
required. It also contains unit tests with almost complete test coverage, which
can help to understand how this all works.

The documentation moved to the documentation website:

* [Plugins](../../docs-website/docs/development/plugins.md) — the plugin
  manager, the kinds of plugins (regular, custom containers, strategy), how to
  define a plugin point, how to implement a plugin, and how custom plugins are
  loaded
* [Plugins in the admin panel](../../docs-website/docs/admin-panel/plugins.md) —
  activating, deactivating and configuring them at runtime
