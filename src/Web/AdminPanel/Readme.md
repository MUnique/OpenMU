# Admin Panel

The admin panel offers the functions for administrative tasks. It's implemented
with ASP.NET Core Blazor Server and hosted by the server process itself.

Its documentation moved to the documentation website, which has one page per
screen:

* [Overview](../../../docs-website/docs/admin-panel/overview.md) — how to open
  it, how it is structured, and how it differs between the deployments
* [Setup](../../../docs-website/docs/admin-panel/setup.md) and
  [Configuration updates](../../../docs-website/docs/admin-panel/configuration-updates.md)
* [Servers](../../../docs-website/docs/admin-panel/servers.md),
  [Accounts](../../../docs-website/docs/admin-panel/accounts.md) and
  [Online accounts](../../../docs-website/docs/admin-panel/online-accounts.md)
* [Game configuration](../../../docs-website/docs/admin-panel/game-configuration.md),
  [Plugins](../../../docs-website/docs/admin-panel/plugins.md) and
  [Chat commands](../../../docs-website/docs/admin-panel/chat-commands.md)
* [Map editor](../../../docs-website/docs/admin-panel/map-editor.md) and
  [Live map](../../../docs-website/docs/admin-panel/live-map.md)
* [Logs and monitoring](../../../docs-website/docs/admin-panel/logs-and-monitoring.md)
  and [Users](../../../docs-website/docs/admin-panel/users.md)
* [Signing in and API keys](../../../docs-website/docs/admin-panel/authentication.md)
* [Common tasks](../../../docs-website/docs/admin-panel/common-tasks.md) — short
  how-tos which combine several of the pages
