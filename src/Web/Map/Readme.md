# Live Map

The live map is a graphical representation of a game map, used to monitor what
happens on it. It's implemented in WebGL (three.js) and uses Blazor's JavaScript
interop to update the visible entities.

Its documentation moved to the documentation website:

* [Live map](../../../docs-website/docs/admin-panel/live-map.md) — what it
  shows, the player list with its follow, disconnect and ban actions, and what
  is planned
* [Admin panel overview](../../../docs-website/docs/admin-panel/overview.md) —
  the rest of the panel which hosts this component
